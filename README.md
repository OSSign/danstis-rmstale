# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [dsnstis/rmstale](https://github.com/dsnstis/rmstale) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [dsnstis/rmstale](https://github.com/dsnstis/rmstale).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/danstis-rmstale/actions).
